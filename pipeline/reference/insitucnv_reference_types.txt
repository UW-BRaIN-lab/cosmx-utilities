# baseline (they are still CNV-profiled downstream, just not used as reference).
# Also excluded: the 14 malignant states (positive control) and Low_signal (the test).
#
# Lines starting with '#' and blank lines are ignored. Names must match obs['cell_type']
# EXACTLY (case-sensitive); any name absent from a given tissue section is skipped with
# a warning by run_insitucnv.py, so this superset is safe to reuse for every section.
